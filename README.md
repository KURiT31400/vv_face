# 顔認証 写真仕分けアプリ

あらかじめ登録した参照画像をもとに、アップロードした写真を顔認証で人物ごとに仕分けし、
**ZIP でダウンロード**できる Streamlit アプリです。

顔認識エンジンは [InsightFace](https://github.com/deepinsight/insightface)（buffalo_l / CPU 実行）、
背番号の読み取りには [RapidOCR](https://github.com/RapidAI/RapidOCR) を使用しています。

## 使い方

1. **① 写真を追加** — 仕分けしたい写真をアップロード（最大 200 枚）
2. **② 解析** — 「未解析を解析」を押すだけ。参照画像の登録は自動です
3. **③ レビュー** — 自動判定を確認し、違うところだけ直す
4. **④ 出力** — ZIP をダウンロード
5. **⑤ 結果** — 人物ごとの枚数や判定一覧を確認、CSV 出力

解析と出力は分かれています。**解析しただけでは仕分けされません。**

## 参照画像の置き方

`ref/` フォルダに、**ファイル名（拡張子を除いた部分）を人物名**として置きます。

| 形式 | 例 | 人物名になるもの |
|---|---|---|
| 1人1ファイル | `ref/MF05_山田太郎.jpg` | ファイル名 |
| 1人1フォルダ | `ref/MF05_山田太郎/01.jpg, 02.jpg …` | フォルダ名 |
| スタッフ | `ref/staff/コーチ_田中三郎.jpg` | ファイル名 |
| その他の関係者 | `ref/etc/MC_鈴木五郎.jpg` | ファイル名 |

同一人物の参照画像が複数あるほど精度が上がります。

**選手**は `ポジション+背番号_氏名` にしておくと、人物一覧がポジション別・背番号順に並び、
背番号での判定も使えるようになります。認識する接頭辞と表示順は次のとおりです。

`GK` → `DF` → `MF` → `FF` → `FW` → `監督` → `SP`（マスコットなど） → `staff` → `etc` → `その他`

**スタッフ・関係者**は `ref/staff/` `ref/etc/` に `役職_氏名.jpg` の形式で入れてください。
`監督_◯◯.jpg` は監督グループとして独立表示されます。

### アプリから参照画像を追加する

**「👥 人物一覧」タブ →「➕ 参照画像を追加する」** からアップロードできます。
追加分は **そのセッション内でのみ有効**で、ブラウザを閉じると破棄されます。
恒久的に増やす場合はリポジトリの `ref/` にコミットしてください。

## レビュー画面

写真の右側は、上から **背番号の検出結果 → 名前で追加する → 仕分け先 → 検出された顔ごとの指定** です。
結論（仕分け先）を先に確認でき、直したいときだけ下の顔を操作する流れです。

**検出された顔ごと** — 顔のサムネイルの下に、自動認識した人物名とチェック欄、その下にプルダウン。

- **確度が高い顔は自動でチェックが入ります**。違うときだけ外す／選び直してください
- 候補は `MF05 山田太郎　(0.523)` のように類似度つきで上位に並び、その下に全メンバーが続きます
- 候補が絞れなかった顔は「その他」と表示されます
- 顔の下に `顔1 / 152px / ボケ度 523` と大きさ・くっきり具合が出ます

**変更は自動保存されます。** 別の写真へ移動すれば保存されるので、「確定して次へ」の押し忘れで
失われることはありません。レビューしていない写真は自動判定の結果で出力されます。

### 取りこぼしを防ぐ

上部に **解析済み / 修正済み / 確認済み / 未確認** が出ます。

| 表示 | 意味 | 一覧の印 |
|---|---|---|
| 修正済み | レビューで内容を変えた | ✔ |
| 確認済み | 開いたが自動判定のまま | ・ |
| 未確認 | まだ開いていない | （なし） |

レビュー対象で **「未確認のみ」** を選び、空になるまで進めれば全部見たことになります。

## 修正した顔を覚える（追加学習）

証明写真だけでは、横顔・斜め後ろ・見上げた顔は判定できません。
レビューで人物を選び直すと、**その顔を本人の参照データとして覚え、次回以降の照合に使います。**

**覚えるのは「修正した顔」だけです。**

| 操作 | 学習 |
|---|---|
| 自動判定が正しく、そのままにした | しない |
| 自動判定を別の人に選び直した | **する** |
| 「その他」だった顔に人物を指定した | **する** |
| 「その他」のまま／チェックを外した | しない |

自動判定の結果を覚えないので、**誤判定が自己強化されることはありません。**

### 学習データの引き継ぎ

このアプリはサーバー上で動くため、**セッション中に覚えた内容はブラウザを閉じると消えます。**
「👥 人物一覧」タブから次の操作ができます。

- **💾 学習データを書き出す** — `learned.npz` としてダウンロード
- **前回の学習データを読み込む** — 次回そのファイルをアップロードすれば続きから使えます

**全利用者に恒久的に反映したい場合**は、書き出したファイルを `ref/.learned.npz` として
リポジトリにコミットしてください。同梱の学習データとして毎回読み込まれます。

## 観客席など、顔が多すぎる写真

検出された顔が **「1枚あたりの最大顔数」（既定 20）** を超えた場合は、
**大きく写っている 3 人だけを照合**し、残りは無視します。
大きい順に選ぶため、観客の前でプレーしている選手が取りこぼされることはありません。

## ボケた顔を無視する

**その写真で最も鮮明な顔に対する比率**（既定 15%）より不鮮明な顔は、背景として無視します。
絶対値は写真ごとに大きく変わるため、比率で判定しています。

## 背番号での判定（背中向きの選手）

背中を向けた選手は顔認証が効きません。そこで **背番号を OCR で読み取り**、
`ポジション+背番号_氏名` と突き合わせて人物を特定します。
**顔で誰も判定できなかった写真にだけ**適用され、顔認証の結果を上書きしません。

看板や観客席の数字を拾わないよう、**文字の大きさ（画像高さ比 5% 以上）** と
**登録メンバーに存在する番号のみ** の2条件で絞り込んでいます。
読み取りは2つの解像度で行い、同じ位置の読み取りは桁数の多いほうを採用します
（大きすぎる背番号が「41」→「4」と割れて読まれるのを防ぐため）。

> ユニフォームのシワや体の角度で読めないことがあります。
> 読めなかった選手はレビュー画面の「名前で追加する」から指定してください。

## パラメータの目安

| 項目 | 説明 | 推奨 |
|---|---|---|
| 類似度しきい値 | コサイン類似度。高いほど厳格 | 0.40（誤検出が多ければ 0.45〜0.50） |
| 最小顔サイズ | これ未満の顔は無視 | 40px |
| 検出解像度 | 大きいほど小さな顔を検出、遅い | 640 |
| 顔検出のしきい値 | 下げると検出しにくい顔も拾う | 0.50 |
| ボケ顔とみなす比率 | 最も鮮明な顔比。これ未満は背景 | 15%（0 で無効） |
| 1枚あたりの最大顔数 | 超えたら大きい3人だけ照合 | 20（0 で無制限） |
| 背番号も読み取る | 背中向きの選手を背番号で判定 | ON |

しきい値・最小顔サイズ・ボケ度（絶対値）は**解析後に変更しても再解析不要**です。
検出解像度・検出しきい値・ボケ比率・背番号設定は再解析が必要です。

## 分割して解析する

写真が多いときは **「1回に解析する枚数」**（既定 50）ずつ処理できます。結果は積み上がります。
解析中は **⏸ 一時停止** と **⏹ 中止** が使え、中止してもそこまでの結果は残ります。

## デプロイ（Streamlit Community Cloud）

1. `public/` の中身をリポジトリのルートに置いて GitHub へ push
2. [share.streamlit.io](https://share.streamlit.io) で Main file path に **`face_app_pub.py`** を指定
3. `requirements.txt` と `packages.txt` は自動で読み込まれます

補足:

- 初回起動時に顔認識モデル（約 300MB）をダウンロードするため、最初の解析だけ時間がかかります
- 無料枠はメモリが約 1GB です。1 回あたり 200 枚程度を目安にしてください
- ZIP が大きい場合は「長辺1600pxに縮小」でサイズが 1/20 程度になります
- アップロード上限は `.streamlit/config.toml` の `maxUploadSize` で調整できます

## 注意

- 顔認証は誤判定を含みます。重要な用途では必ずレビュー画面で確認してください
- マスコット・着ぐるみは顔として検出されないことがあります
- ZIP 内で同じフォルダ・同じ名前になる写真は 1 件にまとめられます

## プライバシー

顔画像は個人情報にあたります。**ご本人の同意が得られている写真のみ**をご利用ください。

アップロードされた写真はサーバー上の一時領域で処理され、セッション終了時に破棄されます。
恒久的な保存や第三者への提供は行いませんが、共用サーバーに一時的にアップロードされる点は
ご了承ください。
